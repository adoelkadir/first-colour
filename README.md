First Colour is a tiny program that delivers a single image: one small robot floating in a grey, monochrome robot city, arms wide in wonder, its chest panel burst open with a rainbow galaxy — magenta, cyan, gold and violet spirals, stars and light rays — pouring out and painting colour onto the grey street below, while the other grey robots stop and stare. The image was generated by an AI agent during a live recorded build; the program copies it to the output path.

## Run it

```sh
OUTPUT_DIR=out npx -y tsx main.ts
```
